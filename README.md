# Saraha App (Anonymous Messaging) Backend

Backend API for an anonymous messaging platform where users can send and receive messages anonymously. Built with Node.js, Express, and MongoDB. Includes JWT authentication, secure messaging, and inbox management.

## Features
- User authentication (JWT)
- Send/receive anonymous messages
- Inbox management
- Input validation and secure data handling

## Tech Stack
- Node.js
- Express
- MongoDB
- JWT
- REST API

## Installation
1. Clone the repo
2. Run `npm install`
3. Run `npm run start`
